# Feature parity

Implemented in the current React/FastAPI foundation:

- Registered material browsing and detail retrieval.
- Validated builder inputs.
- Backend thermal and supported laminate calculations.
- Persisted simulation history and basic comparison/report views.
- Explicit taxonomy and model-compatibility metadata.

Not yet at release parity:

- Authenticated ownership and authorization.
- Persisted reusable material configurations.
- Normalized PostgreSQL schema and migrations.
- Downloadable report files.
- Full metric comparison charts.
- Dedicated models for unsupported catalog families and architectures.
