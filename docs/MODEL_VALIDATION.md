# Model validation status

The existing numerical regression suite covers effective-property equations,
directional CTE, thermal boundary conditions, unsupported CLT systems, finite
laminate inputs, A/B/D assembly, symmetric laminate behaviour, thermal recovery,
and API validation.

The newly added taxonomy is metadata validation, not a new scientific model.
Its unsupported entries are deliberately marked disabled. Dedicated benchmark
validation is required before enabling conductivity, transient, ceramic-matrix,
carbon-carbon, hybrid, nanocomposite, or sandwich models.
