# 17 — Future Scope

Recommended work, not current functionality:

1. Populate reviewed test-specific research datasets with source, original geometry, units, conditions, extraction method, checksums, and provenance.
2. Show per-test usable dataset counts and clear empty-state messaging; preserve missing data instead of inventing curves.
3. Validate models against independent reference calculations and real experiments; document uncertainty and applicability ranges.
4. Build NDT processing only for chosen modalities with real acquisition data and calibration.
5. Govern material properties with source/version metadata and distinguish estimates from measured values.
6. Complete traceable report exports and, if needed, protected accounts and ownership.
7. Define backend hosting, durable storage, backups, monitoring, and operational security.
8. Consider temperature/time-dependent, nonlinear, damage/failure, and higher-fidelity models after validation.
