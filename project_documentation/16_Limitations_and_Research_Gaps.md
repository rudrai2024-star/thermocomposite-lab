# 16 — Limitations and Research Gaps

Material constants are reference estimates and treated as constant over curve ranges. Thermal response is analytical and simplified; no transient heat-transfer, temperature-dependent property, nonlinear response, damage evolution, failure envelope, or FEM solver exists. CLT uses linear elastic plane-stress plies and ideal bonding.

The research schema has zero datasets/observations at the snapshot. No acoustic-emission dataset or other graphable CF/epoxy response set is available. Eight NDT categories are metadata/search entries without modality-specific signal processing; nine destructive tests have simplified metric calculations. Material authoring/persistence, connected login/authorization, parser-to-upload ingestion, and React report export remain incomplete. Software tests do not supply experimental validation, calibration, uncertainty, or measured prediction error.
